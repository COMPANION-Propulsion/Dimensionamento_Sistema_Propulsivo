# Archivio del progetto

- `backups/`: contenuto della precedente cartella `_backups`, con nomi e file conservati.
- `README_pre_riordino.md`: copia integrale del README precedente al riordino.

Questi file servono per consultare le versioni precedenti. Percorsi, comandi e
descrizioni di stato possono essere storici; per lavorare usare il
[README attuale](../README.md). I risultati delle esecuzioni sono conservati
separatamente in [ventola_output/](../ventola_output/).
